# kök Edit — плагин для Adobe Premiere Pro

Синхронизация, AutoCam, паузы, звук, субтитры на казахском и русском, нарезки, проверка перед сдачей.

**Скачать установщик (Windows):** [kok-edit-setup.exe](https://raw.githubusercontent.com/KolenkeMedia/kok-edit-releases/main/installer/kok-edit-setup.exe)

Установщик сам скачает свежую версию. Дальше обновления приходят прямо в плагине — кнопка «Обновить».

Подробнее и подписка — [kok.blue/edit](https://kok.blue/edit)

---

Здесь лежат только готовые сборки. Каждая версия подписана ключом kök — плагин и установщик ставят только версии с верной подписью.

- `channels/main.json` — версия для клиентов, `channels/test.json` — тестовая среда
- `versions/` — описание каждой версии с подписью
- `files/` — части плагина (код, ffmpeg, whisper)
- `installer/` — установщики (`kok-edit-setup-test.exe` — для тестовой среды)
